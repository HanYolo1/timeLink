# Reporting and contributing

## Not sure it's a bug?

Check [common problems](common-issues.md) and [search the issues](https://github.com/HanYolo1/timeLink/issues) first:
someone may have hit it already.

## Report a bug

Open a [new report](https://github.com/HanYolo1/timeLink/issues/new) and include:

- **The version:** the first line of `timeLink_log.txt`, in the game folder's `logs` folder.
- **Your PC:** the operating system, the graphics card and its driver version.
- **What happened,** and where in the game, with the steps to make it happen again if you can.
- **`timeLink_log.txt`** from the run, and a screenshot or a short video.

**Gameplay → Bug report** in the in-game menu gathers the log and your PC's details into one folder in one press, with
your user name taken out. Never attach game files, keys or saves.

## Help with testing

Fixes often need checking on hardware the developer doesn't have: another graphics card, Linux, a Steam Deck. If you
can test something, say so on the issue for that change and report what you saw, including what didn't work.

## Improve the documentation or the code

Read the [contribution guide](../CONTRIBUTING.md) and the [development guide](development.md), then send a pull request
on [Forgejo](https://github.com/HanYolo1/timeLink). For this site, see the
[website instructions](../website/README.md). Questions are welcome on Discord.
